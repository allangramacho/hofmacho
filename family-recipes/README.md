# Family Recipes

A private, mobile-friendly recipe collection for Home Assistant OS. It runs as a Home Assistant app (formerly called an add-on) and is reached through Home Assistant ingress, locally or through an existing Nabu Casa subscription.

Members can browse, search, create and edit their own recipes, add up to five photos, like recipes, and write comments. App administrators can manage all recipes, comments, tags, categories, and which Home Assistant users can use the app.

**Status:** Initial implementation. Test on your Home Assistant instance before relying on it for irreplaceable data. Cross-user recipe links are not yet implemented: ingress URLs must not be copied as share links because they may contain session-specific information. Public links and Google sign-in are not supported.

See the Documentation tab or [DOCS.md](./DOCS.md) for installation, access and backups.
